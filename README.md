# Toronto Blue Jays Daily Reports

This repository contains daily Toronto Blue Jays game reports built with Statcast pitch-level data.

The goal of this project is to create repeatable, data-driven game reviews using pitch movement, swing decisions, batted-ball quality, and situational hitting analysis.

## Latest Report

- [2026-04-28 Blue Jays Advanced Game Report](reports/2026-04-28-bluejays-advanced-game-report.md)

## Current Report Features

- Pitch movement analysis by pitcher and pitch type
- Horizontal and vertical movement profiles
- Pitcher splits by batter handedness
- Contact quality allowed by pitchers
- Batter pitch-type decision analysis
- Chase Rate
- Barrel Rate
- Hard-Hit Rate
- Exit velocity and launch angle analysis
- Situational hitting: runners on vs. no runners
- Spray chart visualization
